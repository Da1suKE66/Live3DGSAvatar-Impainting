# 03 · 没拍到的侧脸怎样补

基于 CherryRH/Live3DGSAvatar 的 feat/geom-v1（5cfbdef3fde47614c636a95308afa72d034e5fcc）。本次是单身份、有同步实拍的筛选实验。先写下比较条件，再生成结果。

1. 从既有单目采集的时间切分中选择可靠跟踪的帧。训练和选模仅用 |yaw| ≤ 10° 的画面。按时间均匀选取最多 192 张训练、32 张验证。重新用正脸训练帧拟合公开 468 点网格的表情形变；原有跨角度模型和纹理不参与初始化。保持真实摄像机、驱动与前景一致。最终取测试段全部 |yaw| ≥ 15° 的帧，左右分开并给出合计；测试段 |yaw| ≤ 10° 每十帧取一张作正脸回退检查。单人连续帧不可当作独立受试者。
2. 用本分支 scripts/train.py 和 train_base.sh 的损失/几何配置，从零训练一个 1200 步 base（种子 1701，公开网格）。从同一个 base 做 250 步对照：真实帧续训；同一组真实帧加未修复的虚拟图；同一组真实帧加论文教师图。教师只看训练参考、同一表情与相机导出的渲染，不接触测试 RGB。虚拟角度 ±20/±35/±50°，保留所有视角和日志。所有对照复用学习率和最终步。实验预算、网格及相机绕转与上游完整 FLAME 训练有差别。修复策略比较不重定义为原论文的完整复现。
3. 主指标为真实侧脸每帧前景 PSNR 和黑底整脸 LPIPS，报告组均值并检查两侧方向及正脸；将每帧数值保留。大角度无同步 GT 的输出只比较可见轮廓/孔洞。禁止用教师修复图充当真值。保留未改善、缺资产及失败日志。
4. 先尝试可直接输出同一相机修复标签的 SyncFix、Difix3D+、EDGAR。其余分别核对并尝试官方权重与最小入口：EG3D 的反演与身份约束；Morphable Diffusion 的 FLAME 表情条件；DiffusionAvatars 的个体与几何缓冲；GAF 的法线条件多视角扩散；FATE 的非正面补全；CAP4D 的多视角生成器；ELITE 的学习型初始化与生成适配。对需要另一套模型/跟踪的路线记录首个实际阻塞和可接入位置。区分下载/输入预检、教师推理和完成 3D 回训三种证据。
5. 每种方法单独提交实现、执行日志、结果或失败依据到 experiments/03-profile-completion。个人画面、模型权重在本地保存。汇总时区分新实测与论文自报表现。
