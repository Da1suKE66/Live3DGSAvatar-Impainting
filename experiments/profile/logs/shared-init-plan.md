# 初始化核验和追加对照

上游每次调用 init_uv.py 都会生成新的表情映射网络。对五个已使用的统一初始化 PLY 逐字段核验，42,566 个高斯的几何和其他字段一致，weight_module 不同。原始完整配方的教师比较因此混有初始化差异。

追加四个对照。原生 SyncFix 已使用的 subject_avatar_unified.ply 的 SHA-256 为 12ab047b5222c2ef52d90302c1bac47adb9b7069dbd435d714bed9a6ed5d45b2。四次训练都显式传入此文件，使用原验证规则、随机种子、视角和标签。只用真实帧、HuFix、EDGAR、各半混合逐一重跑。最终结论以这组为准，前一版结果保留。该修正在看到前一组测试分数之后作出。
