# 大角度掩模敏感性检查

已查看原始掩模和部分大角度预测。极端姿态下，原 468 点脸缘掩模在实拍上缩成月牙，遗漏鼻部、嘴部和面颊。此问题会影响原前景 PSNR 的采样区，也会改变黑底 LPIPS 的参考轮廓。保留已登记的全部原始指标，追加同一批 55 帧、26 个冻结模型的诊断。

使用工作机已有的 MediaPipe SelfieMulticlass 模型，直接从未遮罩的实拍 RGB 取得面部皮肤类别 3。先核验类别标签与掩模覆盖，再在这个共同掩模下比较各方法。PSNR 取面部皮肤区域，在 LPIPS 中对渲染和实拍双方均施加同一掩模，以排除轮廓外背景差异。使用现有的 8 位渲染 PNG，保留该量化差异。按固定角度组及训练种子报告，记录与原脸缘掩模重叠比例。这个诊断依赖自动分类，眼镜、头发和耳部形状不能据此单独判定。
